# 图形学 · 每天一关

用手把图形学拖明白。中文界面，打开就能玩，无需登录。用户侧叫「关」，不叫「天」。

现在做了两关。首页和 `/days` 只列出能玩的关；未做的关用「后面的关还在路上」，没有假标题课表。

## 第 1 关 · 重心坐标把三角形涂满

路由：`/days/1`

拖三个角。指针在三角形里滑动，看颜色怎么兑。把采样点放到正中并钉住，才算过关。扫过重心不算。

## 第 2 关 · 顶点颜色插值

路由：`/days/2`

拖三个顶点上的颜色，让三角里的渐变对上右边的目标。按住色块绕顶点转色相，松手落下；没有调色盘，也没有一键过关。

面上若干采样点都够接近目标后，先出「稳住」，满约 1 秒才算过关。颜色是三个顶点色按重心坐标加权平均。

## 本地运行

需要 Node 22+ 与 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm dev
```

默认地址：<http://127.0.0.1:43147>

```bash
pnpm build
pnpm start -- --port 43147
```

## 技术

Next.js、TypeScript、Tailwind CSS、2D Canvas。填充用重心坐标逐像素插值，不依赖 WebGL。
