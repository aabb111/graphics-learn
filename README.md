# 图形学 · 每天一关

用手把图形学拖明白。中文界面，打开就能玩，无需登录。用户侧叫「关」，不叫「天」。

现在做了四关。首页和 `/days` 只列出能玩的关；未做的关用「后面的关还在路上」，没有假标题课表。

## 第 1 关 · 三个角各占多少

路由：`/days/1`

三个角不能拖。拖取样点看 αβγ 怎么变，再拖到正中的目标环里稳住约 1 秒过关。进关时取样点在一个角附近，空等不能过。过关祝贺只在侧栏。

## 第 2 关 · 顶点颜色插值

路由：`/days/2`

按住上面角上的圆点转色相，让三个角跟下面目标一样。进度跟着三个角色差走；快对上再稳住约 1 秒过关。没有调色盘，也没有一键过关。

## 第 3 关 · 光栅化成像素

路由：`/days/3`

三角固定。点 48px 的粗格子；只有中心落在三角里的格子才能亮着。亮齐后稳住约 1 秒过关。点错的格子不会留下。

## 第 4 关 · 深度缓冲

路由：`/days/4`

两个叠在一起的三角。上下拉改远近，近的盖住重叠处。跟下面目标的前后一致后稳住约 1 秒过关。空等不能过。

## 本地运行

需要 Node 22+ 与 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm dev
```

默认地址：<http://127.0.0.1:43147>

```bash
pnpm build
pnpm start -- --port 43147
```

## 技术

Next.js、TypeScript、Tailwind CSS、2D Canvas。填充用重心坐标逐像素插值，不依赖 WebGL。
