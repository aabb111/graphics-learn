# 图形学 · 每天一关

用手把图形学拖明白。中文界面，打开就能玩，无需登录。

现在只做了第 1 关：**重心坐标把三角形涂满**。首页和 `/days` 留着「第 N 天」的关卡列表，方便以后往下加。

## 第 1 关怎么玩

1. 从首页进入第 1 天。
2. 拖三角形三个顶点，看填充色如何按重心坐标混合。
3. 移动指针（或拖探针）：实时显示 `(α, β, γ)` 和混合色。
4. 三角形外会出现负分量，并标出「在外面」。
5. 极小挑战：把探针放到中心，让三个分量都靠近 `1/3`。

光栅化涂像素、贴纹理、顶点之间的插值，靠的都是这份坐标。

## 本地运行

需要 Node 22+ 与 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm dev
```

默认地址：<http://127.0.0.1:43147>

```bash
pnpm build
pnpm start -- --port 43147
```

## 技术

Next.js、TypeScript、Tailwind CSS、2D Canvas。填充用重心坐标逐像素插值，不依赖 WebGL。
