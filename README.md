# 图形学 · 每天一关

用手把图形学拖明白。中文界面，打开就能玩，无需登录。用户侧叫「关」，不叫「天」。

现在做了两关。首页和 `/days` 只列出能玩的关；未做的关用「后面的关还在路上」，没有假标题课表。

## 第 1 关 · 重心坐标把三角形涂满

路由：`/days/1`

取样点钉在三角形正中。只拖三个角，看中间那三个数。先拖过至少一个角，再停约 1 秒才过关；一进来不拖不能过。过关祝贺只在侧栏。

## 第 2 关 · 顶点颜色插值

路由：`/days/2`

按住左边一个角转色相，让三个角跟右边目标一样。对上后稳住约 1 秒过关。没有调色盘，也没有一键过关。

## 本地运行

需要 Node 22+ 与 [pnpm](https://pnpm.io)。

```bash
pnpm install
pnpm dev
```

默认地址：<http://127.0.0.1:43147>

```bash
pnpm build
pnpm start -- --port 43147
```

## 技术

Next.js、TypeScript、Tailwind CSS、2D Canvas。填充用重心坐标逐像素插值，不依赖 WebGL。
